# Live Catalog search review

All Catalog products, images, sellers, prices and URLs in these screenshots are **mock/sample data**. The production feature flag remains off. The browser intercepts requests; it does not contact Shopify or enroll any service.

Our own search stays above a separately labeled Shopify Catalog section. The samples include a 25% markdown and the exact 5% boundary; a 4% result is rejected. The section appears only after a shopper searches and disappears on error, clear or expiry. First-party product images are blocked in this isolated review browser.
